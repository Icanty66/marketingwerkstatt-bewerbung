Deine öffentliche Arbeitsprobe

Mein Portfolio auf GitHub.

Du bekommst eine Adresse, die du in deinen Lebenslauf schreiben kannst. Für diese Anleitung reichen ein kostenloses GitHub Konto und eine einzige fertige Datei.

1 · Die richtige Datei vorbereiten

Öffne die Portfoliovorlage, wähle „Texte bearbeiten“ und ersetze die Platzhalter. Sichere eine bearbeitbare Kopie für dich. „Lesefassung speichern“ erzeugt index.html für die Veröffentlichung. Öffne diese Datei zur Kontrolle.

Portfoliovorlage öffnen →
Was wird im Internet sichtbar?

Jeder kann die öffentliche Datei ansehen. Nimm nur deinen gewünschten beruflichen Kontakt und die Arbeitsproben auf, die du zeigen darfst. Dein ausgefülltes Kit, Zeugnisse, Notizen, Bewerbungen und die Stellenliste bleiben auf deinem Gerät.

2 · Kostenloses Konto und Ablage anlegen

Melde dich bei GitHub an. Dein GitHub Benutzername steht auf deiner Profilseite. Trage ihn hier ein, damit die Links für dein Konto stimmen.

Konto erstellen ↗ · Bei GitHub anmelden ↗

Auf GitHub heisst diese Ablage „Repository“. Wähle oben deinen eigenen Account, übernimm den Namen, wähle „Public“, aktiviere „Add README“ und klicke auf „Create repository“.

Ablage auf GitHub erstellen ↗

3 · Lesefassung hochladen

Wähle in der neuen Ablage „Add file“, dann „Upload files“. Ziehe die fertige Lesefassung index.html hinein. Klicke auf „Commit changes“. Damit speicherst du die Datei bei GitHub.

Upload öffnen ↗

4 · Seite einschalten und testen

Unter „Settings“ und „Pages“ wählst du „Deploy from a branch“, danach „main“ und „/(root)“. Klicke auf „Save“. Sobald GitHub „Visit site“ anzeigt, öffne den Link auf dem Handy. Erscheinen dein Name, dein eigener Beitrag und die richtige Arbeitsprobe?

Pages Einstellungen öffnen ↗Meine Seite öffnen ↗

Trage in Schritt 2 deinen Benutzernamen ein, um deine persönlichen Links zu erhalten.

Der Link zeigt „404“

GitHub gibt für die erste Veröffentlichung bis zu zehn Minuten an. Prüfe dann unter „Code“, ob die Datei exakt index.html heisst und direkt neben der README liegt. Kontrolliere unter „Pages“ den Zweig und Ordner. Bei späteren Änderungen lädst du die neue Lesefassung unter demselben Dateinamen hoch.
