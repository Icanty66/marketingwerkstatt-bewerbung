Dein Portfolio ins Netz bringen.

Mit einem kostenlosen GitHub Konto veröffentlichst du deine fertige Portfolioseite. Dafür kannst du eine eigene HTML Seite aus ChatGPT oder die Lesefassung aus dem Atelier verwenden.

1Lesefassung vorbereiten

Speichere deine fertige Seite aus ChatGPT als index.html und öffne sie zur Kontrolle. Nutzt du die Vorlage aus dem Atelier, ergänze deinen Namen, deinen eigenen Beitrag und deinen Kontakt. Mit „Lesefassung speichern“ erhältst du dieselbe Dateiart.

Portfolio bearbeiten

Für die öffentliche Seite: Lade ausschliesslich die geprüfte Lesefassung hoch. Verwende freigegebene Bilder und Texte. Lebenslauf, Zeugnisse und Bewerbungsmappe behältst du privat.

2Ablage bei GitHub anlegen

Konto erstellen ↗ oder anmelden ↗. Trage hier deinen Benutzernamen und einen Namen für deine Ablage ein.

Du findest ihn in deinem GitHub Profil. Er steht in der Adresszeile hinter github.com/. Bei GitHub heisst die Ablage Repository. Der Name wird Teil der öffentlichen Adresse.Ablage erstellen ↗

Wähle deinen Account, „Public“ und „Add README“. Klicke auf „Create repository“.

3Eine Datei hochladen

In der neuen Ablage öffnest du „Add file“ und „Upload files“. Ziehe index.html in das Fenster. Mit „Commit changes“ speicherst du sie bei GitHub.

Upload öffnen ↗

Der Link wird aktiv, sobald oben beide Namen eingetragen sind. Deine Datei soll direkt neben der README liegen.

4Seite einschalten und öffnen

  1. Öffne „Settings“ und dann „Pages“.
  2. Wähle „Deploy from a branch“, dann „main“ und „/(root)“. Klicke „Save“.
  3. Öffne „Visit site“ und prüfe die Seite auf deinem Handy.
Pages öffnen ↗Meine Seite ansehen ↗

Deine Adresse erscheint, sobald du die Namen eingetragen hast.

Eine neue Seite braucht mitunter zehn Minuten. Bei „404“ prüfe Dateiname, Zweig und Ordner. GitHub Anleitung ↗
